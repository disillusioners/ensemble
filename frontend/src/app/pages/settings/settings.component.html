Agent Snapshots

The snapshot subsystem captures instance experience for warm starts (R14 auto-fallback). The write side (snapshot_create) is gated by this toggle; the read (snapshot_search) and consumption (spawn_hot_instance) tools are always-on (R15 rider isolation). Default: off (opt-in rollout). When off, snapshot_create calls return a clean disabled result and spawn_hot_instance falls back to a cold spawn whenever no snapshot was found. Snapshots capture only what still exists at creation time — instance context expires after about 168 hours (the checkpoint TTL), so long-off periods mean older completed work is no longer snapshotable.
