- **Phase**: P2
- **Workstream(s)**: WS-3 (G1 perf — journal splice), WS-4 + WS-5 (G5 — pending-op heartbeat writer + daemon sweep three-signal read)

## 1. Objective

**Replace the 139 s/read bash brace-walk with a stdlib-only python helper that does O(1) json round-trip per journal event** (the measured difference between 28–46 min of journal overhead on a clean promote and <1 min). Close the **armed→flip misclassification window** from ~37 min today (slow bash walk + field declared without writers) to <2 min (helper + 30 s `lock_heartbeat` cadence → `in_flight.last_heartbeat` + three-signal sweep that combines heartbeat freshness, `os.kill(pid, 0)`, and cgroup-leaf match).

**ENTRY GATE — `ENVSIM_BASELINE=1` pre-change timing capture BEFORE the splice lands.** The AC1/AC2 evidence narrative depends on the measured before/after delta, not the digest's quoted figures alone. Capture numbers on the pre-change HEAD; archive the artifact in this planning directory; THEN begin T2.2.
