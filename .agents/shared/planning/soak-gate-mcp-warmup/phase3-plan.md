## Objective

Make a failing MCP server fail alone, fast, and visibly. A per-boot quarantine registry (module-level in the SINGLE leaf home
`daemon/mcp/init_guard.py`, consulted by the existing `is_available()` classmethod at
all three verified sites) gives "disabled for this boot" a real home; a NEW init-path guard reuses the
single `CircuitBreaker` primitive (`daemon/sources/circuit_breaker.py:20`, lock-protected mutators
only) to drive the quarantine after N init failures, with a bounded, off-loop, per-attempt DNS
pre-check (probe, never pin; against the resolved base the child will actually use) failing fast on a
dead host; context7 gains the two-variable env schema (`CONTEXT7_BASE_URL` defaulted,
`CONTEXT7_API_URL` deliberately unset) with a validating `build_config` and the `schema_version`
"2"→"3" bump; the readiness `detail` gains the per-server `detail.mcp` map plus journal lines per
state transition, and the stale top-level `reasons` reader in `upgrade_tools.py` is fixed. The phase
ends with the four A5 sub-cases as the final gate and the staged-verification protocol for the
v0.27.9 slot (re-derived at stage time).
