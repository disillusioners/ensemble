# Phase 1: FE Tabs Wire-up (Part 1)

> **Cluster 1 of 6** — the FE shell rewrite for `mat-tab-group` per the frozen design spec. Independent of Part 2 (VACUUM FULL). The work is a self-contained Angular port: import `MatTabsModule`, extend `MaintenanceSection` with `disabled?`, replace the `@for + *ngComponentOutlet` template with `<mat-tab-group>` + `<mat-tab>` (using `@for` control flow, NOT `*ngFor`), append the SCSS overrides and the sticky wrapper, update the mirror spec's section count, and add 4 new source-grep pins (pin count 18 → **22**, adjudicated per §D-7.7).

## Objective

Port `MaintenanceComponent` to the frozen design spec §3.1: a `mat-tab-group` with Tab 1 ("Checkpoint", active by default, mounts the existing wizard as-is) and Tab 2 ("Database", disabled with "Coming soon" tooltip). The section registry stays load-bearing; adding a future tab is one line. The tab bar is sticky; the page-header scrolls out first; lazy-mount is preserved; theme tokens reuse the existing `$bg-*` / `$text-*` / `$accent-cyan` SCSS variables — no new color literals.
