# Phase 3: FE Wizard Checkbox + Payload (Part 2 frontend)

> **Cluster 3 of 6** — the FE wizard internal change: extend the `CheckpointCleanupExecuteRequest` model with `vacuum_full?: boolean`; add a checkbox + helper text in the wizard's confirm step (Step 4 area, near the "Cleanup now" button); default state is checked; thread the value into `performExecute()`. The wiznav-fix non-regression envelope is preserved (the checkbox is INSIDE the wizard, not at the page-shell level).

## Objective

Add a one-checkbox-deep operator opt-in: when the operator is at the wizard's confirm step (the "Confirm Cleanup" step in the existing 4-step Material stepper), a new checkbox labeled "VACUUM FULL (reclaim disk space)" appears, DEFAULT TICKED, with a one-line helper text below. The checkbox's state threads into the execute payload as `vacuum_full: <boolean>`. The wiznav-fix envelope (pointer-events header fence; `event.selectedIndex + queueMicrotask` revert gate; NO `editable=false` on any mat-step; footer Back works; auto-advance on succeeded) is preserved by construction — the checkbox is a form-field inside Step 4's form area, not a stepper-chrome change.
