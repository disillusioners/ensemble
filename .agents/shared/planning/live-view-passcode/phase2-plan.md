# Phase 2 — Public Lane: `/views/public` routes, interstitial, grant cookie, rate limit, `view_link` change, reserved-root guard

## 1. Objective

Open the ONE new unauthenticated surface — `/views/public/{root}/{path}` — inside the
existing live-views router (`build_router()` at `daemon/routers/live_views.py:499`, which
is mounted app-level BEFORE the SPA catch-all, `daemon/api.py:4097-4099`), gated entirely
daemon-side: no valid grant cookie → zero-JS interstitial; POST verify (the only POST on
the whole /views surface) checks rate limit → strike counter → constant-time compare →
issues a stateless path-scoped Fernet grant cookie → serves content through the SAME
resolution/render pipeline as the direct lane. `view_link` (`daemon/tools/live_views.py:97`)
returns URL + passcode on every mint with a `refresh` param. The direct
`/views/{root}/{path}` family stays byte-identical (requirement 5).

## 4. Acceptance Criteria

| ID | Criterion |
|----|-----------|
| AC3 | Direct lane byte-parity: for the same file, pre-feature and post-feature direct `/views/{root}/{path}` responses are byte-identical (status, headers, body) — pinned by a before/after capture test |
| AC4 | Every `view_link` result contains both the public URL (`/views/public/...` form, external-base-qualified when configured) and the passcode, as stable labeled lines |
| AC5 | Default `view_link` is idempotent: repeated mints return the SAME passcode; `refresh=True` returns a DIFFERENT passcode and invalidates the old one |
| AC6 | A legacy view (no passcode row) lazily mints on the next `view_link` call for the same path — no backfill migration exists or is needed |
| AC7 | Anonymous flow: GET public URL with no cookie → zero-JS interstitial (CSP + nosniff headers); POST correct code → 303 + grant cookie; subsequent GET within TTL renders content without interstitial |
| AC8 | Grant cookie: ~24h TTL enforced; scoped `Path` to the view; generation-mismatch (post-refresh) and tampered cookies both fall back to interstitial; passcode NEVER appears in any URL or query string |
| AC9 | Method surface: POST exists ONLY on the public view path; per-IP bucket rate-limits verify (429) WITHOUT consuming strike counter attempts |
| AC12 | Uniform-404 preserved on the public lane for: unknown root, unknown path, traversal, extension-not-allowed, torn sidecar, never-minted public view — identical envelope to the direct lane |
| AC16 | A configured root named "public" is rejected at boot (config validator) — reserved-root guard proven |
| AC17 | Lockstep sweep clean: no agent-prompt/doc reference to view_link's shape or /views URLs is stale post-change; seal re-pin adjudicated if triggered |
