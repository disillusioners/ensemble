## 1. Objective

Build the request-path gate: `AuthMiddleware` (pure ASGI, conditionally
registered, LIFO-outermost), `AuthService` (login URL build, callback
handling, session validate/invalidate), the 4 auth routes, redirect_uri
resolution via `BaseURLResolver` reuse, the public-path set (D18: derived
from route metadata) + SPA PUBLIC-ASSETS rule, and the 401-vs-302
contract. This phase is where the protection matrix ([REQ] §5) becomes
executable.

Entry prerequisites: P1 (config), P2 (store + OAuthClient).
