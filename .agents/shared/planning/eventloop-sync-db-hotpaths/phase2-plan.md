# Phase 2: C-1 + T-2 — the instances surface (+ the children-order gate + the `include_descendants` pair)

## Objective

Collapse the instances children N+1 into ONE batched statement and move the instances list/detail endpoints off the event loop, so that the loop thread never sits in an instances-path DB frame (the G1 target) and the flat badge leg's loaded p95 stops inflating 13× purely from loop queueing — **while making the children-order gate strong enough that the one permitted normalization cannot mask a real drift.**

**Grouping rationale (post-fold, D-40):** C-1 (`daemon/routers/instances.py:476`) and T-2 (`daemon/routers/instances.py:346`, `:550`) touch the **same router file** — grouping them keeps one developer instance's context on `instances.py` and avoids two instances editing one file. **This file's two-site rationale is INTACT after the fold** (unlike `jobs_crud.py`, which lost T-3 to the deferral).

**Fold round 3 changes to this phase (binding — `decisions.md` D-70, D-78):** exit criterion 6 is **re-scoped (AB-5/B5 — the round-2 "ZERO deleted lines" form was UNSATISFIABLE**: tasks 2.2/2.3/2.4/2.6(c) each delete or modify lines ⇒ ≥5 deletions for any correct implementation, which would RED a correct phase or induce a falsified proof); task 2.4 states **`by_parent.get(instance_id, [])`** so a childless instance yields `[]` (matching BASE); and task 2.2 carries the **C-1 observation-window disclosure** (the batched children SELECT shares D-B's window — mirrors risk 7).

**Fold round 2 changes to this phase (binding — `decisions.md` D-54, D-63, D-65):** the **detail path is ROUTED, not re-queried** — `daemon/services/instance_lifecycle.py:5143` goes through **`list_child_ids_for_parents([instance_id])`**, and **`list_child_ids_permanent` is FORBIDDEN to touch** because it has **four production co-callers outside this lane's compared set** (D-54/W-9, tasks 2.2/2.4/2.7(c)); the exit criterion restates **six files** with **mechanical additive-only** proof — `git diff -U0` over the touched files has **zero deleted lines** and **both P1 constant names are still present** (D-63/W-8); and task 2.1 gains the **no-chunking** sentence (D-65/A-8).

**Fold round 1 changes to this phase (binding):** the children-order gate is amended by the architect's **FIVE corrections** (D-34/§5.2: multiset, per-parent AND global, static SQL pin, ALL returned rows, detail path shares the ordered source); `include_descendants` becomes the **(c)+ ruling** (D-33/§5.1/R5: keep + **named pair** + **two internal call sites explicit** + docstring); the batch must cover **241 rows, not just the roots**.
