# Phase 1: Offload infrastructure (`daemon/services/db_offload.py`)

## Objective

Land the single off-loop execution seam every C-class site in this lane consumes — a dedicated `ThreadPoolExecutor` (6 workers, `thread_name_prefix="db-offload"`) plus `await offload(fn, *args, **kwargs)` — with the executor-selection, admission-gate, re-entrancy, `BaseException`, contextvar, error-propagation, **drain** and backpressure contracts **proven in isolation before any production call site adopts it**.

This phase is the reason the lane is sequenced this way: P2, P3 and P4 all consume `offload`, so its signature and semantics must be frozen at this phase's exit (see Exit Criterion).

**FOLD ROUND 4 changes to this phase (binding — `decisions.md` D-79, D-80, D-81; approver iteration-002 RB1/RB2 + notes F3/F4/F8/F11):** the gate's permit accounting is **NO-RESERVE** — waiters hold NO permits; `permits == workers == in-flight` at all times; a cancelled parked waiter **removes itself from the deque and returns nothing** (RB1/D-79, task 1.4 + pin (ix) restated); the cross-thread wake primitive is **NAMED** — `loop.call_soon_threadsafe(waiter.set_result/set_exception, ...)`, thread-safe future RESOLUTION (not coroutine scheduling), with the loop captured once at `configure()` (RB2/D-80, tasks 1.1/1.3/1.4 + the TB-5 amendment); `wrap_future`'s cancellation semantics are stated CORRECTLY (F3); the single-loop cooperativity assumption is explicit (F4); the drain hang-case sentence is added (F8); the alarm threshold form is named (F11).

**FOLD ROUND 3 changes to this phase (binding — `decisions.md` D-66, D-67, D-74, D-78):** task **1.1 names the executor-substitution form** — `Executor.submit` + `add_done_callback` on the **concurrent** future + `asyncio.wrap_future`; **`loop.run_in_executor` is NEVER used on the seam path** (D-66/AB-1/F-3 — the round-2 text contradicted D-43); task **1.4 replaces `asyncio.Semaphore` with a CUSTOM gate** (permit counter + waiter deque + atomic register-then-check close + defined post-close errors; D-67/AB-2 — a semaphore cannot fail parked waiters and exposes no waiter count); **pin 1.9(x) is STRENGTHENED** to assert **max concurrent thread executions ≤ W under a cancellation storm** (D-66/M-1); `DB_OFFLOAD_DRAIN_BOUND_S` gets its **numeric default 10 s** with the ⊂90 s arithmetic (D-74); and the D-78 cheap notes land (configure() contract/idempotence, P1 exit-3 wording, the re-entrancy pin's `asyncio.run` vector, the `:420-428` citation).

**FOLD ROUND 2 changes to this phase (binding — `decisions.md` D-43, D-52, D-53, D-55, D-59, D-64, D-65):** the admission gate is **fully specified** — **permits == the resolved `max_workers` value**, release in the **executor future's done-callback** (never the caller's `finally`), plus cancellation pins **(ix)/(x)** (D-43/C-2, task 1.4; the permit count is the **resolved `max_workers` value**, never a bare `DB_OFFLOAD_MAX_WORKERS` symbol — that name does not exist, D-55); re-entrancy is detected by **THREAD IDENTITY** and `CancelledError` is **re-raised before any `BaseException` handler**, with pin **(xi)** (D-52/W-13+W-14, tasks 1.5/1.6); the drain is **FOUR-STEP** with **`DB_OFFLOAD_DRAIN_BOUND_S`** and a **waiter-failure pin**, inside `TimeoutStopSec=90` (D-53/W-12, task 1.7); the executor is constructed **LAZILY via `db_offload.configure()` from the lifespan** with a **subprocess** override pin and **aligned constant names** (D-55/W-10, tasks 1.2/1.3); the TB rule set gains **TB-8** (D-64, task 1.11); P5 adds a **source-scan pin over `daemon/`** for every `offload(` site (D-59/W-17, task 1.11); and **A-5/A-7** wording fixes land in exit criterion 6 and task 1.8(a) (D-65).

**FOLD ROUND 1 changes to this phase (binding):** the module is **renamed** `db_bridge.py` → **`db_offload.py`** and the API `run_db` → **`offload`** (D-20/A8); the seam **accepts kwargs** (D-25/A6/R7); sizing is **6 workers** (D-21/A2/R8); the shutdown premise is **corrected** and a **bounded drain seam** is added to the lifespan (D-24/A5/R6); the mandatory amendments **B1, B2, B4, B6, B7, B9, B10** are folded as tasks with pins (D-26/A7 + A10); the executor-identity pin asserts the **thread-name prefix** (D-27/A9); **F4-A is NOT claimed** as the bridge's protection (D-23/A4).
