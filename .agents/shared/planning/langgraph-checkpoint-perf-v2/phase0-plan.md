- **Independent of:** Phase 1..5 (purely precondition)
- **Phase 0 → Phase 1..5:** Every subsequent phase references `phase0-state.md` / `phase0-pre-counts.md` / `phase0-baseline.md` / `phase0-grep-baseline.md` as the comparison baseline. If T0.5 baseline is GREEN, every subsequent regression is the port's fault.
