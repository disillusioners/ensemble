# Phase 1 — Schema, PG materialization, persona seed

**Depends on:** P0. **Flags consumed:** #14 (whole phase), #8 (mirror schema + the dormant approve seam), #6 (column families), #13 (the seed is knob-INDEPENDENT).

## 1. Objective

The durable substrate: ONE `.sql` migration (SQLite-valid, additive, audit record), four SQLModel tables registered before `create_all`, the PG `tsv` generated column + GIN index via the `_ensure_postgres_columns` ensure, and the §11 persona seed shipped VERBATIM via a boot-time get-or-create that can never abort boot.

## 2. Decisions

| ID | Decision | Rationale (verified anchors) | Rejected alternatives |
|----|----------|------------------------------|------------------------|
| D1.1 | ONE `.sql` file `…_create_memoir_tables.sql` with all four tables | the commission mandates ONE; `20261020_060000_create_board_tables.sql` is the multi-table single-file house precedent (3 board tables, one file) | one-file-per-table (PSL style) — allowed but not mandated |
| D1.2 | The `.sql` is SQLite-valid only, and **every string column is declared TEXT**: `embedding TEXT`, `stars TEXT` | house rule: every string column is TEXT on both drivers; the model's SQLite DDL emits JSON affinity (benign under SQLite dynamic typing) but the two artifacts must not be read as equivalent — **pin it** | carrying PG-specific types in the `.sql` (breaks every SQLite boot — the 20260714 breaker class) |
| D1.3 | PG tables via model registration immediately before `SQLModel.metadata.create_all(self._engine)` | verified site: registration block `daemon/manager.py:920-975` (board `:953-960`, bash_spawn `:961-965`, PSL `:966-973`), `create_all` at `:975` — the brand-new-table operative artifact (PSL A10 ruling) | `_ensure_postgres_columns` as the table-creation path (that hook is for COLUMN evolution on existing tables) |
| D1.4 | `tsv` in NO SQLModel class; PG-only idempotent ensure: `ALTER TABLE memoir_episodes ADD COLUMN IF NOT EXISTS tsv tsvector GENERATED ALWAYS AS (to_tsvector('english', coalesce(title,'') \|\| ' ' \|\| body)) STORED` + `CREATE INDEX IF NOT EXISTS idx_memoir_episodes_tsv ON memoir_episodes USING GIN (tsv);` — the **TWO-ARG** form | the two-arg `to_tsvector(regconfig, text)` is **immutable** (legal in a `GENERATED … STORED` expression); the one-arg `to_tsvector(text)` is **STABLE** and PostgreSQL **rejects it** (*"generation expression is not immutable"*) ⇒ the one-arg form breaks the PG boot. House PG is 16.15 ⇒ no version-floor risk (`'english'::regconfig` is equivalent and may be used for clarity) | the one-arg form (rejected by PG); a `Computed` tsvector in the model (breaks SQLite `create_all` — SQLite has no `to_tsvector`); dialect-conditional ORM column (SQLAlchemy cannot vary a STORED expression per dialect) |
| D1.5 | The two memoir ensure statements go **LAST** in the ensure list | the ensure executes one statement per list element in **one transaction** with **no per-statement try/except** (`daemon/manager.py:8269`) and house fail-loud stands (`manager.py:8259-8265`: *"the exception propagates and startup aborts … There's nothing to swallow"*) — a memoir-specific failure must abort the boot loudly, not be swallowed into a half-indexed table | swallowing the failure (produces a half-indexed table that fails later, at query time, far from the cause) |
| D1.6 | Ensure anchors (P-7-corrected): the ensure **function** is `_ensure_postgres_columns` at `daemon/manager.py:8055`, **called** at `:997` (PG-gated on `config.is_postgres`); the house precedent for a column added to a `create_all`-created table is `ALTER TABLE … ADD COLUMN IF NOT EXISTS` at `:9481-9484` | verified this session; the ensure's own statement list begins at `:8269` | the `:838-883` region — a **comment block**, not the function (P-7 lead-vs-truth); the ensure is the **creation path** for `tsv` (a column the ORM cannot express on SQLite), not a "belt" |
| D1.7 | **Boot order is pinned:** (1) model registration → (2) `create_all` (`:975`) → (3) migration runner (`:980`) → (4) `_ensure_postgres_columns` (`:997`, including the memoir `tsv` ALTER + GIN) → (5) persona seed (after (2); the seed is an INSERT into `memoir_persona`, so it CANNOT run before `create_all`) → (6) `api.py` lifespan: the worker task starts **LAST** | the seed is an INSERT ⇒ table-first; the worker is a consumer of a live schema ⇒ last | seeding inside the migration file (the runner is SQLite-only ⇒ PG would never be seeded) |
| D1.8 | `StarsListType` contract: `impl = JSON`, `cache_ok = True`; `load_dialect_impl` → `dialect.type_descriptor(ARRAY(Text()))` on PG, `JSON()` otherwise; **identity** `process_bind_param` / `process_result_value` returning a **Python list on BOTH drivers** (never a pre-serialized JSON string — that would be re-encoded on PG); column stays **nullable** (`None` ≠ `[]`); **never a mutable default** (`default=None` / `default_factory`); element type `Text()` so PG renders `TEXT[]` | house "never VARCHAR"; the dual-driver `JSONBType` pattern at `daemon/repositories/infra/types.py:35-70`; a pre-serialized string value would be double-encoded on PG | plain `JSONBType` everywhere (loses PG-canonical `TEXT[]`); a mutable `default=[]` (shared-mutable default — a classic bug); identity-breaking string passthrough (double-encoding on PG) |
| D1.9 | Embedding identity as SIBLING columns (`embedding_model TEXT NULL`, `embedding_dims INTEGER NULL`, `embedded_at TEXT NULL`) beside the JSONB vector, + `embedding_attempts INTEGER NOT NULL DEFAULT 0`, `embedding_error TEXT NULL` | `critical_note_embeddings` carries `model`+`dims` as queryable columns (`daemon/repositories/project/models.py:293-347`); attempts/error are the worker's durability substrate (flag #7) | identity inside the embedding JSON object (not queryable; the worker scan would deserialize) |
| D1.10 | The four embedding columns are written by **one atomic column-targeted UPDATE** (`embedding`, `embedding_model`, `embedding_dims`, `embedded_at` together) | a partial write leaves `embedding IS NULL AND embedded_at IS NULL` true ⇒ the row is re-embedded **forever** | four separate writes (partial state ⇒ infinite re-embed) |
| D1.11 | Persona: `memoir_persona` (agent_id PK, current_version_id, updated_at) + `memoir_persona_versions` (id, agent_id, version, body, status CHECK in (draft,pending_approval,approved,rejected,archived), source ∈ {seed,ari,operator}, submitted_at, approved_at, UNIQUE(agent_id,version)); the transition vocabulary is **mirrored** in the memoir repository | `VALID_TRANSITIONS` verified at `daemon/repositories/prompt_version/repository.py:217-221`; mirroring keeps DD-9's gate without prompt-cache/UI coupling | reusing `prompt_versions` rows (wrong artifact family — prompt-cache invalidation, selection machinery, prompt-versioning UI) |
| D1.12 | The **dormant approve seam ships the human-lane guard** in v1: `approve()` raises `HumanLaneRequiredError` unless `actor.auth_method == "session"` (house discriminator, `daemon/services/prompt_version_service.py:678-716`; the router maps it to `403 HUMAN_LANE_REQUIRED`) — ~15 lines, **no new surface** | without the guard, DD-9 is **decorative** the moment v2 adds a submitter: a mirror of only the transition vocabulary lets the first v2 submitter reach `approved` with no human in the loop. `submit()` has **no caller in v1** (no tool, no route) | shipping only the transition mirror (decorative safety); adding a v1 submit path (re-opens §5.4's five-tool surface, the 18/5/4 census, an FC9 delta and a new auth scope **for zero v1 capability**) |
| D1.13 | Seed via boot-time idempotent get-or-create (`source='seed'`, born `approved`), seed text constant `MEMOIR_PERSONA_SEED` in `daemon/repositories/memoir/seed.py`; **a seed failure MUST NOT abort boot** — log `WARNING [Memoir] persona seed failed: <exc>` and continue | the runner is SQLite-only — a migration INSERT would **never seed PG** (the operative path); the persona is **content, not schema** — a failed seed must not stop the daemon | migration-carried INSERT (a silent PG gap — a defect dressed as a mechanism); aborting boot on a seed failure (content failure escalated to an availability failure) |
| D1.14 | `memoir_syntheses.source_episode_ids` typed **JSONBType** | the table is schema-only and EMPTY in v1 (DD-2) ⇒ array-vs-JSON has **zero behavioural effect**, and the dual-driver JSON type keeps the `.sql` SQLite-valid. Recorded so the divergence from design §4.4's `[]` sketch is not rediscovered later as a defect; revisitable in v2 under the same dual-driver constraint | a native ARRAY column (breaks SQLite `create_all` for zero v1 behaviour) |
| D1.15 | Timestamps: `DateTime(timezone=True)` for created_at/event_at/pinned_at/last_accessed_at; `embedded_at`/`submitted_at`/`approved_at` ISO-8601 TEXT (the PSL/critical-notes string convention for provenance stamps) | ordering correctness either way; provenance stamps are display-first | all-TEXT timestamps |

## 3. Tables (exact proposed DDL — Phase B owns types/indexes/naming per design §4.1)

**`memoir_episodes`** — `id` (uuid4-hex TEXT PK, repository-minted), `agent_id` TEXT NOT NULL, `title` TEXT NULL, `body` TEXT NOT NULL, `created_at` ts NOT NULL, `event_at` ts NOT NULL (app-level default = created_at), `importance` INTEGER NOT NULL DEFAULT 5 CHECK (importance BETWEEN 1 AND 10), `stars` StarsListType NULL, `is_keepsake` BOOLEAN NOT NULL DEFAULT 0, `pinned_by` TEXT NULL CHECK (pinned_by IN ('empress','emperor')), `pinned_reason` TEXT NULL, `pinned_at` ts NULL, `last_accessed_at` ts NULL, `access_count` INTEGER NOT NULL DEFAULT 0, `embedding` JSONBType NULL, `embedding_model` TEXT NULL, `embedding_dims` INTEGER NULL, `embedded_at` TEXT NULL, `embedding_attempts` INTEGER NOT NULL DEFAULT 0, `embedding_error` TEXT NULL, `superseded_by` TEXT NULL REFERENCES memoir_episodes(id).
Indexes: `idx_memoir_ep_agent_created (agent_id, created_at DESC)` (dynamic zone); `idx_memoir_ep_agent_event (agent_id, event_at)` (timeline); partial `idx_memoir_ep_keepsakes … WHERE is_keepsake` (`sqlite_where`/`postgresql_where` — the resource_monitor precedent at `daemon/models/resource_monitor.py:260-268`); partial `idx_memoir_ep_pending_emb … WHERE embedding IS NULL` (worker scan). PG-only: `tsv` generated + GIN (D1.4).

**`memoir_persona`** / **`memoir_persona_versions`** / **`memoir_syntheses`** (schema only, EMPTY — DD-2; columns per design §4.4: claim, `source_episode_ids` **JSONBType** (D1.14), valid_from/valid_to TEXT NULL, verb CHECK in (CREATE,CORROBORATE,REFINE,CORRECT), supersedes/superseded_by TEXT NULL, confidence REAL, created_at ts).
