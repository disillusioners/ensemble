## The first-non-privileged-write-category consequence (accepted, not a risk to be closed)

universe. Every tools-less custom agent inherits it. This **is** the user requirement ("all
agents"), and it is the reason the category is non-privileged at all — a privileged category
would need an explicit grant for every empty-allow agent and would change 17 assertion sites.

Mitigations already in the lane: per-agent rate limits (pre-harvest), clustering (N reporters →
one row), the kill-switch, and the scrub pipeline. **Accepted and disclosed.**

## Standing house rules this register assumes

- `env -u POSTGRES_*` is a **silent NO-OP** — scrub env vars **one by one**.
- `cd agents/ && sha256sum -c` yields 161 spurious FAILEDs — the house
  `scripts/protection/generate_prompt_artifact_baseline.py --check --tree <root>` is the only
  authority.
- A frozen-binary boot smoke is **not** isolated by default (the binary's path derivation
  resolves the live install root) — the scratch-dir + per-var-scrub + explicit
  `ENSEMBLE_BOOT_SWEEP_STALE_SUBPROCESSES=0` discipline and the byte-fences are the
  compensating evidence.
- The stage-time prompt-artifact drift check is **read-only and journaled, never gating** (the
  allow-stale policy); the boot-time drift check is **WARN-only, non-blocking**.
- Promote is **never** planned here. The user's 3-factor nonce ceremony owns the flip.
