# Phase 2: Boot continue-pass service + api.py wiring + kill-switch

## Objective

A new `daemon/services/auto_continue_boot_pass.py` module implements the continue pass as pure orchestration over existing primitives (AC2), wired into the lifespan at `daemon/api.py:1522` (after `sweep_wake_records`, before `upgrade_journal_sweep.start()`), gated by `ENSEMBLE_AUTO_CONTINUE_RUNNING_ON_RESTART` (default ON, `=0` disables, per-boot read — AC9), wrapped in the wake-sweep's three-layer never-wedge envelope (AC6). RUNNING-only (AC1): PAUSED parked, terminal untouched, WAITING_CHILDREN skipped.
