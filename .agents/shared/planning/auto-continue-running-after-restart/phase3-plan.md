# Phase 3: Coexistence ordering + pinning (AC4)

## Objective

Prove — with an executable pinning test plus a negative lock-out test — the exact interleaving between the pending_wakes sweep and the new continue pass when BOTH target the same instance (an arming instance that was mid-turn RUNNING at daemon death). The invariant: continue-in-place keeps the orphan Task `status='running'` → the claim-guard (`repository.py:2230-2294`) blocks the wake's PENDING claim → the wake lands FIFO-behind the continued turn (arm-notify UX: outcome report AFTER the turn finishes). Terminalize-early (Interleaving Y) must be structurally impossible in shipped code.

## Risks

- **Test determinism**: the interleaving test spans two async subsystems (wake sweep journal I/O + the pass) + StaleTaskRecovery. Mitigation: temp-dir journal + deterministic LLM stub + `asyncio` race-free sequencing (await each boot slice to completion before assertions); no sleeps. **For row 5 (STR mid-flight reap):** time-shrink STR's threshold OR inject the reap directly via `force_cancel_and_schedule_retry` to make the test deterministic — the row tests the BEHAVIOR (reap → checkpoint retry), not the wall-clock aging.
- **Claim-guard surface drift**: `claim_pending_task` internals are load-bearing for the test; anchors drift. Mitigation: import + call the public method, never copy SQL into tests; grep-verify any cited line at use time against D23 verified anchors (claim-guard at `repository.py:2230-2294`).
- **Structural-pin brittleness**: source-scan assertions break on formatting changes. Mitigation: assert on stable tokens (function names, `await` targets), not line numbers, except the 3.5 ordering pin which is deliberately order-sensitive.
- **Δ1 mutual exclusion with row 5**: row 4 (Δ1 success path) and row 5 (STR mid-flight reap) describe opposite-conditional behaviors — Δ1 makes row 4 deterministic; row 5 still applies to TURN >10 min (heartbeat-free window, R20). The tests must be parameterized so they don't conflict (row 4 = turn <10 min OR turn where heartbeat is fresh; row 5 = turn >10 min OR heartbeat stale).
