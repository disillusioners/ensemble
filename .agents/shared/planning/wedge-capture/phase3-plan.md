# Phase 3 — Test packs, isolated boot smoke, staging checklist

Phase objective: **prove** the instrument works (including on a *simulated* wedge), prove it does not violate
the house test traps, and land it as a **stage-only** release.

Depends on Phase 1 (instrument) and Phase 2 (read-back surfaces).

Authoritative tree: `/home/nea/ensemble-src-wt-wedge-capture` (base `639b7129b`).

---

## 1. Objective

1. **Unit packs** covering every branch the design can fail on: trigger thresholds/sustain/cooldown/de-dup;
   capture-writer atomicity, failure-swallowing and pool-independence; the boot record including the **OFF
   early-return branch**; the read-back list/fetch; the registry registration.
2. An **ISOLATED boot smoke** that proves the instrument **fires and captures on a simulated wedge** — with
   tiny thresholds and an artificial loop block / CPU burn in the harness — and proves the **cooldown** holds.
3. **House-trap compliance** (the traps that have bitten this project before).
4. The **stage-only** release checklist with the rollback-safe adjudication written out (STANDING RULE).
