What's in the box

Four primitives, one event store.

Everything you need to ship a production analytics surface — without standing up a warehouse.

01 / SQL

ANSI SQL, not a DSL

Joins, window functions, CTEs against an event table. The query you wrote in dev is the query that runs in prod.

02 / Stream

Live dashboards

Charts re-render in under a second as new events land. Webhooks, ingest API, or CSV — all stream into the same model.

Anomaly alerts

Define a metric, set a band. Slack or PagerDuty the moment the value leaves it — no thresholds to babysit.

Audit-ready outputs

Every query is logged. Pipe results to CSV, Parquet, or straight into S3. SOC 2 Type II, GDPR-ready by default.
