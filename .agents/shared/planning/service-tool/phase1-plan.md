- **Code rollback:** revert commits; drop the migration (write a DOWN migration if the table needs explicit cleanup — mirror `20260906_192100` DOWN section).
- **Data rollback:** `DROP TABLE IF EXISTS service_tracking;` (PG) or equivalent SQLite drop; reverse the `_ensure_postgres_columns` extension.
- **Hot-unwind mid-flight (post-merge):** flip env to 0 + restart; existing rows stay; no in-flight services are killed (by design — services are kill-exempt; the reconcile sweep just stops marking EXITED).
