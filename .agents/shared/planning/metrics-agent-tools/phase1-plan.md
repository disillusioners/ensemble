## Objective

Make the frozen query substrate **reachable and typeable** by its first consumer, without touching any contract surface: (1) extend the `MetricsQueryProvider` Protocol ADDITIVELY so the tool layer is typed against it with no `Any`/`getattr` escape (the house lesson: *"a Protocol that no consumer references guarantees nothing — extend the Protocol BEFORE typing the consumer"* — `.agents/tidier/notes.md:762`); (2) promote the seam's own duck-typed numeric-fact reader to a public name; (3) mount the ONE live provider on the manager beside `app.state.metrics_query` (D-UX-12); (4) pay the audited two-fake mechanical cost; (5) pin all of it.

This phase adds NO tool, NO category, NO route, NO scope. It is the prerequisite substrate Phase 2 consumes.
