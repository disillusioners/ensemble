**Commission:** resource-cost-control · **Spec:** `architecture-recommendation.md` §2.1, §2.4, §2.5, §2.8 (`/live` + `/history` endpoints), §2.8/§5 (self-cost regression test), §2.9 (config) · **Slice:** 1 of 8 (P1 → P2 → P3 → P4 → P5 → P6 → P7 → P8)

## 1. Goal

Stand up the observability spine: ONE `threading.Thread(daemon=True)` sampler (cgroup v2 + raw `/proc` hot path, **no psutil**), ONE flusher thread (batched `executemany`, roll-down, retention sweep), the 4 `resource_*` tables (dual-dialect per-table migrations), the `resource_monitor:` config block (all knobs per §2.9), the first **three** API endpoints (`GET /api/resources/live`, `GET /api/resources/history`, **`GET /api/resources/self-cost`**), and the **self-cost regression test** (the self-cost budget is an acceptance criterion, not a nicety). Worktree stays GREEN and independently mergeable at this boundary.

Non-goals for this phase: attribution (P2 fills `attributed_bytes`/`unattributed_kb`/`coverage_pct` — in P1 those T1 columns exist but are written as NULL/0 defaults), join/traceback (P3), anomaly layer (P4), FE (P5), control surface (P6).
