## 1. Objective

At the end of Phase 1:

1. The agent-facing repair tool's dry-run path contains **no explicit `BEGIN`** and **rolls back on every exit path**, including the failure of the rollback itself.
2. The readiness probes carry a **server-side** bound on their own statements, sized from their own asyncio budget, so an abandoned probe worker cannot hold a connection open indefinitely. The probe's *client-side* classification is unchanged, and the leak detector / grace machinery is **byte-identical**.
3. The mission boot mint is **idempotent**: a second mint for the same anchor returns the winning epoch and raises no `IntegrityError`, and the caller's transaction is not poisoned.
4. The lane publishes an **honest** audit record: ~689 borrow sites audited, **0 unclosed borrows**; RCA sites B and C recorded as audited-and-clean with their premise corrections.
5. **(NEW — F8)** The deferred-report reconcile holds **no** manager-engine transaction across an await; the static AST pin (F8-a) is GREEN; the PG pin (F8-b) shows zero manager-pool idle-in-txn backends attributable to the reconcile; the concurrent-escalation pin (F8-c) shows no double delivery; the write-atomicity pin (F8-d) shows the message/task/injection writes still commit in one transaction.
