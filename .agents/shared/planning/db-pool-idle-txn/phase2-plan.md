# Phase 2 — Pool hardening (F2) and the wedge-capture correctness fix (F5)

- **Phase objective:** harden the manager engine's pool knobs (exact values, one table, one pin), add the engine-level server-side timeout backstop that completes F4's defense-in-depth layer (**REVERSED for statement_timeout per C-3**), pin the repair engine's reset semantics explicitly, attribute all three pools distinctly (C-8), and fix the wedge-capture table name.
- **Base:** `19fc11c8b52239813fd91327ee0c1961c5b6fc87`.
- **Depends on:** Phase 1 (the F4 probe-scoped bound is already live, so the engine-level layer lands on a working baseline; F8 has removed M-R3 so the idle-in-txn bound can be sized safely).
- **Carried from the overview:** couplings C1-C5, risks R1-R19, safety-precedence rule.
- **Sibling artifacts referenced by filename only:** `test-strategy.md` (the lane's gate ladder detail — the PG runner forms quoted here come from it), `audit-method.md` (census method + counts), `wi-78967dba-verdict.md` (verdict), `final-implementation-spec.md` (binding contract), `BASELINE.md` (Phase 0 evidence).

## 1. Objective

At the end of Phase 2:

1. The manager engine's pool configuration is **explicit on every knob that matters** — `pool_pre_ping`, `pool_reset_on_return`, `pool_recycle`, `pool_timeout` — so the "an aborted connection is never handed out" property is a **pinned invariant** rather than an implicit library default.
2. The manager engine carries **server-side** `idle_in_transaction_session_timeout` (the `statement_timeout` is DROPPED per C-3) and `application_name=ensemble-manager` (D-30), so no backend on that engine can sit in `idle in transaction` indefinitely, and future censuses can attribute backends to pools.
3. The repair engine — the pool that produced the incident's `BEGIN` fingerprint — has its reset semantics pinned explicitly, carries `application_name=ensemble-repair`, and **every one of its existing knobs is unchanged**.
4. The asyncpg checkpoint-adapter pool gets `application_name=ensemble-checkpoint-adapter` on a **separate DSN** (C-8), without touching the shared `conn_string` (P2 oracle immutability).
5. The wedge-capture queries read the correct table (`task`, not `tasks`), so the capture stops aborting its own transaction on the first read and the second/third reads stop failing with `current transaction is aborted`.
6. The **honesty blocks** that name this lane as the owner of an unfixed P1 leak are refreshed (R12 + A9-v).
