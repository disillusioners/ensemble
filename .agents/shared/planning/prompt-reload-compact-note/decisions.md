## 2. The Emperor's architectural direction (verbatim — AUTHORITATIVE; engine ruling PENDING)

> *"For this feature you can upgrade, reuse the existing compaction feature of system or write new one (dreamer/distill agent). It take messages and your compact note then produce new context. This module can use decision engine (jev model) to quickly filter messages before feed to dreamer compaction agent."* [emperor]

This direction **OPENS** two capabilities (an engine choice; a jev pre-filter). It does not **CHOOSE** either. The choice is the architect's; it is carried as ES-1 and ES-2/ES-8.

**Ari's RECOMMENDATION — recorded as a recommendation-INPUT to ES-1, NOT as a decision:**
UPGRADE the existing pipeline rather than build a parallel engine — it already owns the summarizer, the dedicated model, the ceiling rules, the sentinel mechanics, the cost plumbing, and the section structure the note must compose with. The "dreamer" becomes a **NOTE-GUIDED MODE** of that pipeline, not a second engine. Add: (a) the note-injection layer; (b) an **OPTIONAL** jev PRE-FILTER stage (cheap triage of candidate messages BEFORE the expensive summarizer sees them), with its own budget + kill switch, degrading gracefully (jev unavailable/over budget → skip the filter, compaction proceeds normally — never a hard dependency); (c) an explicit seam-safety proof that the pre-filter can never drop a message the note references as settled. The note-guided distillation is a **WORKING-CONTEXT mirror of the memoir dream lane** — keep the two conceptually separate (episodic vs working memory) but document the kinship.
