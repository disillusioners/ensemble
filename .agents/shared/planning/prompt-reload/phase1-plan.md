> **Rev 2 fold:** AM-1..AM-3 (manifest scope/reader/absence), AM-5 (tri-state divergence), AM-6 (final refusal vocabulary), AM-7 (no seam guard), AM-8 (hash decision + cache bust), AM-9 (repo probe), AM-11 (per-call kill-switch), AM-12 (delegate skeleton), AM-13 (no lock + claim-guard), AM-14 (mcp_tool_names parity) folded from `architecture-recommendation.md`. Decisions D2/D3/D5/D6/D11 are DECIDED; D22/D23/D24 live in `decisions.md`.

## 1. Objective

A typed, reusable manager-level primitive `refresh_instance_prompt` that performs the whole validate → compose → compare → pop cycle for ONE instance (the caller's own), returning a structured result. The `prompt_reload` tool (Phase 2) and the future compaction path (R8, NOT wired here) both call this. All reasoning anchors from plan-overview §4–§5 apply.
