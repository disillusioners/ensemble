## Implementer closeout notes (2026-11-06, implementation lane)

No [IMPLEMENTER-BLOCKER] rows — the plan proved implementable as written. Two implementation notes for the record (both within the plan's authority):

- **[IMPLEMENTER-NOTE] D14 per-file vs persona-level delta split.** D14's grammar ("per artifact file → `+N/-M lines`, byte delta, sha256 before→after") cannot yield per-file LINE deltas: the baseline map (D5, pinned) stores file HASHES only — the "before" file BYTES are gone at call time, and the composed persona is not structurally attributable per file (sections are only positionally ordered).
