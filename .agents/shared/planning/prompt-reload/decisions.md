## Leader rulings (DECIDED — binding)

| ID | Decision | Source |
|----|----------|--------|
| R1 | Mechanism = bare pop (`manager.instances.pop(own_instance_id, None)`). Tool: validate → rebuild via the standard loader path → compare → pop if changed/forced → return diff+provenance. NO graph building, NO `_release_cached_instance` (probe P4: proven zombie-maker), NO closure mutation, NO tuple swap (P5: 23-arg rebuild, drift). | Leader ruling, binding (probe-validated P3/P4/P5/P7). |
| R2 | Single source of truth: composition ONLY via `load_and_cache_prompt` (or its exact helpers). No own .md reading/diffing of composed prompts. Per-file hashing for provenance = reporting, allowed. | Leader ruling, binding. |
| R3 | Old-persona extraction from the graph closure FORBIDDEN (langgraph-internals-brittle). Evaluate loader-cache-based diff (exact when cache == closure — the normal case, P2) + honest fallback (report new composition + provenance only, delta unavailable). Consider per-file sha256 structural alternative; claim persona-level equality only when the loader fingerprint is unchanged. | Leader ruling, binding. |
| R4 | Self-only scope: the tool reloads THE CALLING instance's own agent prompt (factory-captured agent_id/instance_id; no caller-supplied target, not even optional). | Leader ruling, binding. |
| R5 | New privileged category `prompt-reload`; allow-list ari EXACTLY (notify-user precedent: three-layer gate incl. in-body factory-captured agent_id). `tool-categories.json` regenerated via the house generator only (F-1 trap class). Pin ceremony per house rules; privileged pin census updated. | Leader ruling, binding. |
| R6 | Guardrails: idempotent no-op on unchanged persona (clear message, NO pop); optional `force=true` re-emits; typed refusal ladder (dir validation self-env-aware, manifest verification, loader/DB errors fail-closed). Never write conversation history; never touch other instances. | Leader ruling, binding. |
| R7 | Breadcrumb: evaluate tool-return-as-breadcrumb vs injected persistent note. Leader leaning: tool-return ONLY, no persistent injection. | Leader ruling, binding leaning; architect confirmation = OQ3. |
| R8 | Expose the validated reload as a manager-level primitive callable by BOTH the tool and (future, optionally) the compaction path. Compaction integration OUT OF SCOPE this lane. | Leader ruling, binding. |
| R9 | Docs note provider prompt-cache invalidation as an accepted consequence. | Leader ruling, binding. |
