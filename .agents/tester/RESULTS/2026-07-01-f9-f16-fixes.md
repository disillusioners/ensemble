### Quick Fix Applied — Regression in `_derive_legacy_status`

**Root cause**: `_derive_legacy_status` accepted any truthy `terminal_reason`. Test `test_reconcile_terminal_jobs` passes a MagicMock job whose `terminal_reason` attribute auto-creates a truthy non-string MagicMock, which `canonicalize_status` returned verbatim. The non-string `legacy_status` failed the `status in watcher.watch_events` check, silently swallowing notifications.

**Fix** (commit `89491465`, 1-line change in `daemon/services/work_status.py`):
```python
# Before
if admission_state == "done" and terminal_reason:
# After
if admission_state == "done" and terminal_reason in _STATUS_CANONICAL_MAP:
```

Gates the discriminator on canonical-map membership so non-string truthy values fall through to the lossy `done → completed` map fallback.

**Verification**: All 1314 job_queue tests pass + all 37 F16 tests still pass after fix.
