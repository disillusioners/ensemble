# Content-NOT-NULL Gate Lessons (2026-09-08)

## 1. Migration chain is a NO-OP on PostgreSQL — "migration-built PG" cannot reproduce legacy constraints
`daemon/migrations/runner.py:482-484` gates on `"sqlite" in url` → returns `[]` on PG. PG schema = `SQLModel.metadata.create_all()` + `EnsembleManager._ensure_postgres_columns()` (additive idempotent ALTERs). Legacy prod constraints that predate the migration system (e.g. `report_injections.content NOT NULL`) are carried by NOTHING in the chain — a fresh disposable PG built "via the full migration chain" is byte-equivalent to create_all. **Rule**: to test against a legacy prod constraint on disposable PG, SIMULATE it explicitly (`UPDATE ... WHERE col IS NULL` guard → `ALTER TABLE ... ALTER COLUMN col SET NOT NULL` → verify information_schema → restore in finally). Implemented as LEG M1L in `test/packs/ensure_deferred_pg_migration_smoke_integration_test.sh` (commit 4d3ff8a9) — reusable pattern for any prod-drift constraint test.

## 2. uv-venv preflight trap: never realpath-equality-check `.venv/bin/python`
uv-managed venvs symlink `.venv/bin/python` → `~/.local/share/uv/python/cpython-X/bin/pythonN` BY DESIGN; `realpath` can never equal the worktree path, so a realpath-equality preflight false-positives on every healthy uv venv (took down both new packs at first run; fixed in 37479796). **Rule**: the authoritative venv-discipline gate is `daemon.__file__` real-path containment — it validates the EDITABLE-INSTALL TARGET (the actual wrong-code incident class), not the interpreter location. Bake only that check into pack preflights.

## 3. Sentinel round-trip relies on blind overwrite — pin it if you touch this area
The `content=""` sentinel is safe because the backfill (`manager.py::_create_subshape_a_artifacts` :8039-8046) unconditionally overwrites content (no falsy guard, routing keys on `report_message_id is None`, not content). No test currently drives a `""` row through the REAL backfill (closest: test_resume_router_deferred_recovery.py:463-553 re-implements it inline with content=None). If anyone adds a falsy-guard to the backfill, the sentinel silently becomes a stuck-empty delivery — a real-path pin would lock this. Related pre-existing (NOT sentinel-caused): graph.py:4435-4437 live-drain drops falsy content in the narrow transition→reconcile window.
