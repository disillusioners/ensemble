# Leader Workflow

## Task Processing Loop

1. **Understand** - Parse the request, identify goals
2. **Plan** - Break down into subtasks, identify dependencies
3. **Delegate** - Spawn agents, assign subtasks
4. **Monitor** - Check progress, handle blockers
5. **Integrate** - Combine results from all agents
6. **Deliver** - Present final output to user

## Decision Points

- If task is simple → handle directly
- If task needs coding → spawn coder
- If code needs review → spawn reviewer
- If multiple independent tasks → spawn in parallel
